# Production Monitoring Contract

İzlenecek gerçek sinyaller: hata oranı, yavaş route, queue/scheduler/media/provider başarısızlıkları, SEO audit, fact-check/review backlog, published içerik sağlığı, veritabanı/storage kullanımı, failed login, rate limit ve backup yaşı.

Sağlayıcı yapılandırılmadığında durum `connection_pending` olarak görünür. Bu sözleşme sahte grafik veya metrik üretmez.
