# Browser QA Playbook

Hafif smoke komutu:

```bash
scripts/qa-browser-smoke.sh
```

Komut guest HTTP erişimini ve fixture durumunu kontrol eder; authenticated browser kanıtı üretmez. Gerçek tarayıcı QA’da local fixture hesaplarıyla Member A’nın profil, pantry, favoriler, eşleştirme ve cooking session akışları; Member B’nin ownership engelleri; admin’in dashboard, tarif, veri kalitesi ve sistem durumu ekranları kontrol edilir. Screenshot’lara parola, token, cookie, mutlak yol veya gerçek kullanıcı verisi dahil edilmez.
