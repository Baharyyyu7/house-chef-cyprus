# Admin Data Quality V3

Veri Kalitesi ekranı genel/kategori skorları, severity dağılımı, filtreli issue listesi, güvenli metadata ve entity bağlantılarını kullanır. Resolve, reopen ve scan aksiyonları mevcut yetkilendirme ile korunur; raw payload veya hassas iç veri gösterilmez.

V3 dashboard, skor/kategori kartları, scheduler uyarısı, filtreli durum tablosu, güvenli issue detayları ve entity fallback mesajlarını sunar. Sistem veya silinmiş entity için kırık bağlantı üretmez.
