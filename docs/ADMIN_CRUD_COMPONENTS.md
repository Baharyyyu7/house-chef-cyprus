# Admin CRUD Components

Part 2 ortak V3 sözleşmesi:

- `x-admin.page-header`: eyebrow, breadcrumb/back link ve yetkili aksiyonlar.
- `x-admin.filter-bar`: tutarlı GET filtreleri ve temizleme davranışı.
- `hc-admin-table-shell`: yoğun masaüstü tablo ve kontrollü yatay mobil taşma.
- `hc-admin-form-card`, `hc-admin-tabs`, `hc-admin-sticky-save`: uzun formlarda bölüm, dirty-state ve görünür kaydetme alanı.

Ölçü, dönüşüm, nutrition, alerjen/diyet ve data quality yönetimi bu sözleşmeyi kullanır. Mobilde tablo bilgi kaybı olmadan kontrollü yatay kaydırılır; desktop'ta sticky başlıkla okunabilir kalır.

Hareketler reduced-motion tercihinde kapatılır. Durumlar yalnız renkle ifade edilmez.
