# Smart Shopping List

Liste, plan tariflerinin malzemelerini birleştirir ve geçerli pantry canonical miktarını düşer. Bilinmeyen miktar açıkça işaretlenir; opsiyonel malzemeler saklanır. Purchased/undo durumu liste sahibine özeldir. Alerjen hard filtreyi aşan tarif planlanmadığı için alışveriş önerisi de üretilmez.
