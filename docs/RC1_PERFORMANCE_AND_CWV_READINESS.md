# RC1 performans ve Core Web Vitals hazırlığı

Yerelde doğrulanabilir kanıtlar: Vite production build, seçilmiş kolon/eager loading/pagination sözleşmeleri, cache, responsive media ve statik UX performance kontrolüdür. LCP/CLS/INP saha metriği, gerçek cihaz/hız/ağ ve production telemetry olmadan raporlanmaz.

Production sonrası gerçek RUM veya izleme sağlayıcısı üzerinden baseline ve bütçe tanımlanmalıdır.
