# RC1 go-live önerisi

Kod tarafında RC1 önerisi yalnız `BLOCKER=0` ve `CRITICAL=0` olduğunda `ready_for_prelaunch_human_qa` olur. Bu, production yayını onayı değildir.

Go-live için yetkili sahip; domain/DNS/TLS, production environment, SMTP, yedek hedefi, monitoring, gerçek cihaz-browser/assistive-tech QA ve insan editoryal/media onaylarını ayrı ayrı kanıtlamalıdır.
