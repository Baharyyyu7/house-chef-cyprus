# İnsan İncelemesi Operasyonları

İnsan incelemesi yalnız admin tarafından yapılır. İnceleyici, taslak detayında güvenli metadata ve açık fact-check konularını görür; onay, ret veya revizyon isteği kendi kullanıcı kimliği ve denetim kaydıyla saklanır. Otomatik süreç hiçbir kullanıcıyı taklit etmez.
