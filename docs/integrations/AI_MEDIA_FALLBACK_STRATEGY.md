# AI Media Fallback Strategy

1. Use an already approved, article-specific synthetic illustration when present.
2. If none exists, retain the intentional text-only public state; never substitute another article's image.
3. Stock providers may create private candidates only after their own licence and identity checks.
4. If every provider is unavailable, preserve the brief and prompt history and mark the job waiting for a provider. No fake file, misleading image, or automatic publication is allowed.
