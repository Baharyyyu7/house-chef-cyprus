# AI Media Cost and Quota Policy

`AI_MEDIA_ENABLED` and provider-specific credentials remain environment-only. A zero configured budget is a hard stop for billable application providers. The approved twenty-blog editorial batch is versioned artwork generated through the authorized built-in workflow and has no runtime provider call.

No deployment, queue retry, or scheduled command may create an unbounded generation loop. New billable providers require owner confirmation of terms, quota and cost before activation.
