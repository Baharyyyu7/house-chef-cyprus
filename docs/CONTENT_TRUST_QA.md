# Content Trust QA

`data:quality-scan`, kaynak eksikliği, doğrulanmamış yayın, görsel lisansı ve measurement güveni için issue üretir. Content Trust kategori skoru kaynak, verification ve yayın güveniyle ilgili açık issue'ların severity ağırlığından hesaplanır. `recipes:completeness-report --json` katalog tamlık sonucunu makine tarafından okunabilir biçimde sunar.
