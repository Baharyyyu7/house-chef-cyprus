# Typography System

`hc-display-*`, `hc-heading-*`, `hc-body-*`, `hc-label-*`, `hc-caption`, `hc-overline` and `hc-code` define hierarchy. Display text is reserved for one page title/hero; operational admin text uses body/label levels. Long Turkish labels must wrap rather than overflow. At 200% zoom, content stays in one logical reading order.
