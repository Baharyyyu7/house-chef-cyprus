# Personalization Profile

Profil isteğe bağlı onboarding, açık tercihler ve gizlilik ayarlarını tutar. `explicitly_selected` tercihler, inferred sinyallerden ayrı tutulur. Kullanıcı profili güncelleyebilir, personalization'ı kapatabilir ve öğrendiği verileri silebilir. Admin kullanıcı tercihlerini değiştiremez.
