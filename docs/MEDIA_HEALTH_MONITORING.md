# Media Health Monitoring

`media:health --json` reports coverage, review queues, duplicate groups, private leakage and the current score. `media:morning-brief --json` adds a bounded priority list. The scheduled fidelity, licence and attribution audits only prepare review records; they do not publish media.

Operations also retain existing orphan and temporary-file scans. Provider health reports only enabled/configured state and counts—never secret values.
