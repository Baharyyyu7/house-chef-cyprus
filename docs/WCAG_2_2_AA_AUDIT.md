# WCAG 2.2 AA Audit

Automated guardrails cover skip navigation, theme tokens, reduced motion, labelled fields/alerts and shared focus styles through `ux:accessibility-audit --json`. The report is deliberately not a WCAG certification.

Manual closure is required for keyboard order, focus traps, 200% zoom/reflow, actual contrast measurement, screen-reader landmarks/headings/live regions and touch targets on 320–430px devices.
