# Production Blog Standard

Bir production blogu benzersiz başlık/slug, amaç, search intent, özgün giriş, anlamlı H2/H3, kaynak gerektiren iddiaların izlenebilirliği, ilgili içerik bağlantıları, SEO metadata, canonical, schema, media brief, alt text ve editoryal inceleme durumuyla değerlendirilir.

Kopya metin, sahte uzman görüşü, kaynaksız sağlık iddiası ve birbirinin aynısı meta açıklama kabul edilmez.
