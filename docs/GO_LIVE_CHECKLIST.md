# Go-live Checklist

Human sign-off is required for: real domain/DNS/TLS; hosting and writable paths; non-SQLite database; backup/restore test; cron/queue; SMTP/SPF/DKIM/DMARC; monitoring; secure headers; canonical/sitemap/robots/search verification; analytics consent; legal/editorial/media review; deployment/rollback owner and on-call contact. Technical readiness never replaces this approval.
