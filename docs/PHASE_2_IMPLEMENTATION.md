# Faz 2 Uygulaması

Faz 2 Türkçe tek içerik diliyle çalışır. Public ULID, units, nutrition facts, allergen/dietary ilişkileri, provenance alanları ve API v1 eklendi. Çoklu dil tabloları özellikle ertelenmiştir.

Import Engine bu fazda tamamlanmış olarak kabul edilmez. Uygulamada aktif connector, import
komutu veya import queue işi yoktur. Bu alan Foundation V1.5 backlog'una ertelenmiştir.
