# Tarif Completeness Modeli

Skor; temel bilgi, malzeme, household/canonical ölçü, grup, adım, ekipman, püf noktası, saklama, nutrition, allergen, dietary, medya, provenance ve editoryal kontrol kategorilerinden oluşan açıklanabilir 0–100 puandır.

- `incomplete`: temel içerik eksik
- `needs_review`: içerik var, kritik kontroller eksik
- `ready_for_review`: taslak incelenebilir
- `publishable`: kontrol listesi tamamlandı

Skor tek başına yayın yetkisi vermez; ayrıca `verification_status=verified` gerekir.
