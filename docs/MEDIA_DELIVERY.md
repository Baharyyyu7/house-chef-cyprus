# Media Delivery

Public delivery uses an approved-media gate. Recipe and blog surfaces fall back to branded presentation when no approved real asset exists. Approved local media exposes responsive URLs and `srcset`; Unsplash delivery uses its official image URL contract. The configuration provides a CDN base URL seam without coupling domain code to a CDN vendor.

Image sitemaps and structured data exclude all private, placeholder, unverified, licence-incomplete and attribution-incomplete records.
