# Content Graduation Pipeline

Tarif: `draft → technical_review → fact_check_review → editorial_review → media_review → seo_review → ready_for_final_approval → human_approved → scheduled → published`

Blog: `draft → originality_review → fact_check_review → editorial_review → seo_review → media_review → ready_for_final_approval → human_approved → scheduled → published`

Geçişler audit edilir. Final insan onayı ayrı, yetkili bir aksiyondur; yalnız admin yayın aksiyonu gerçek entity durumunu değiştirebilir. Blocker bulunan içerik sonraki kapıya geçirilemez. Hiçbir geçiş `verified` değeri veya yayın tarihini otomatik üretmez.
