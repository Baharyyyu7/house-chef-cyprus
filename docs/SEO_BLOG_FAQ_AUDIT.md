# SEO, Blog & FAQ Audit

## Mevcut

- `public/robots.txt` tüm crawler’lara izin veriyor.
- Public recipe/detail URLs, Türkçe `lang`, basic description ve responsive viewport meta mevcut.

## Eksik / Backlog

- XML sitemap / image sitemap
- Canonical URLs
- Recipe, Organization, Breadcrumb, FAQ ve Article JSON-LD
- OG/X social metadata
- About, How It Works, FAQ, Editorial Policy, Privacy, Terms route’ları
- Blog list/detail/category/tag modeli
- Internal linking policy, broken-link check ve content hub IA

Bu alanlar çalışıyormuş gibi değerlendirilmemelidir. Önce P1/P2 data trust ve media düzeltmeleri, ardından SEO Content Hub fazı önerilir.
