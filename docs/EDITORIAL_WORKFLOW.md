# Editorial Workflow

Bir brief; kullanıcı sorusu, hedef kitle, niyet, gerekli bölümler, ilgili tarifler, yasak iddialar, kaynak notları ve freshness gereksinimini içerir. Taslaklar editoryal onaya kadar public değildir.

İnceleme sırası: kaynak/fact-check → özgün katkı → editoryal doğruluk → SEO açıklığı → medya doğruluğu → zamanlama. Benzerlik kontrolü yalnız House Chef içeriğindeki başlık/özet için erken uyarıdır; insan kararı yerine geçmez.
