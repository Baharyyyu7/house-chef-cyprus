# Product Experience Health

`ux:audit --json` provides a static guardrail snapshot and records `rule_version`, generated timestamp, surface files, semantic findings, score caps and manual QA requirements. `ux:responsive-audit`, `ux:accessibility-audit`, `ux:theme-audit`, `ux:state-audit`, `ux:performance-audit` and `ux:health` expose focused, safe JSON views.

Scores are capped below 100 because they are not field telemetry, browser measurements or human acceptance. The admin **Ürün Deneyimi** page displays this distinction.
