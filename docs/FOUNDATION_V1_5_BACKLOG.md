# Foundation V1.5 — Import Engine

Import Engine bilinçli olarak ertelenmiştir; mevcut uygulama manuel/demo içerikle kararlı kalır.

- Tam pipeline, demo/gerçek connector, validation DTO ve duplicate candidates: ilk gerçek kaynak seçildiğinde.
- Retry/backoff, failed imports, raw payload güvenliği ve import testleri: 100+ tarif içe aktarımı veya otomatik güncelleme öncesi.
- Kaynak/lisans doğrulaması ve gerçek API bağlantıları: dış veri lisansı doğrulandığında.
- Import yönetim ekranları ve veri kalitesi raporları: otomatik veri güncellemesi başlatıldığında.
