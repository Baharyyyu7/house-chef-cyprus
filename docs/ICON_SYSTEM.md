# Icon System V3

Tek standart `x-ui.icon` inline SVG primitive'idir. Ölçüler 14, 16, 20, 24 ve 32 px; aynı stroke, round cap/join ve optical alignment kullanır. Dekoratif icon `aria-hidden`; anlam taşıyan icon `label` ile `role=img` alır.

Navigation, status, empty state ve button ikonları emoji/metin sembolü yerine bu primitive'e taşınır. Ingredient icon sistemi bu fazda production verisine yayılmaz; ileride `docs/INGREDIENT_ICON_SYSTEM.md` sözleşmesine bağlı ayrı manifest ile gelir.
