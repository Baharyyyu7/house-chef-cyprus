# Nutrition Confidence

Tamamlanma, güvenle hesaplanabilen malzeme ağırlığının toplam ölçülebilir malzeme ağırlığına oranıdır. Güven puanı, mevcut fact kayıtlarının confidence değerinin tamamlanma oranıyla çarpılmasıyla elde edilir. Eksik veya güvenilir dönüşümü olmayan malzeme sahte kesinlik üretmez; sonuçta açıkça listelenir.
