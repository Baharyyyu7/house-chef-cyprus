# Tarif Kaynak Politikası

Kaynak kayıtları public identifier, tür, ad, URL (varsa), lisans, dil/ülke, erişim zamanı, confidence ve doğrulama durumunu taşır. Kaynak metinleri veya görseller kopyalanmaz. `seed_demo`, `editorial_estimate` ve `ai_assisted_draft` kayıtları insan doğrulaması olmadan verified/published değildir.
