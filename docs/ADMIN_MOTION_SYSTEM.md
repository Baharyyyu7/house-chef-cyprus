# Admin Motion System

Admin V3 hareketleri yalnız yönlendirme ve geri bildirim içindir: page reveal, kart stagger, hover lift, drawer slide, sayısal count-up ve Chart.js chart reveal. Varsayılan süreler global `--hc-duration-*` tokenlarından gelir.

`prefers-reduced-motion: reduce` altında tüm geçişler pratik olarak kapatılır; count-up ve chart animation çalışmaz. Motion, ölçüm veya kritik sistem bilgisini geciktiremez.
