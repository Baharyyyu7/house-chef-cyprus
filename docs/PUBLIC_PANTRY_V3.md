# Public Pantry V3

Pantry V3, kullanıcı sahipliğindeki malzemeleri household ölçüsüyle saklar. Canonical karşılık yalnız güvenli dönüşüm varsa ikincil olarak gösterilir; belirsiz dönüşümler kesin bilgi gibi sunulmaz.

Süresi geçmiş ürünler listede korunur ancak matching aktarımına dahil edilmez. Pantry kaydı yalnız sahibince güncellenebilir veya silinebilir.
