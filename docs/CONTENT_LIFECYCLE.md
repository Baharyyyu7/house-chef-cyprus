# İçerik yaşam döngüsü

Tarif: `idea → research_ready → brief_ready → draft → technical_review → fact_check_required → editorial_review → ready_for_human_review → human_approved → scheduled → published`.

Blog: `idea → research_ready → brief_ready → draft → originality_review → fact_check_required → editorial_review → seo_review → media_review → ready_for_human_review → human_approved → scheduled → published`.

`technical_failed`, `editorial_failed`, `rejected` ve `archived` terminal/güvenlik durumlarıdır. Fabrika başlangıçta `ready_for_human_review` taslağı oluşturur. İnsan onayı, doğrulama veya yayının yerine geçmez; her biri açık, yetkili bir aksiyon gerektirir.
