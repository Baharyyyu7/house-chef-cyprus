# SEO Entity Model

Semantic signals come from real domain records only: recipes link to cuisine, category and ingredients; blogs link to an editorial category, tags and verified recipes; `keyword_topics` and `content_topic_clusters` hold human-curated editorial planning data.

No entity is automatically presented as verified, authoritative or a search demand signal. Topic records require editorial review before they are counted as approved. Public identifiers, never internal numeric IDs, are used in operational displays and integrations.
