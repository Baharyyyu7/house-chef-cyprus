# RC1 medya regresyonu

Yalnız `approved_real_media`, lisans ve attribution incelemesi tamamlandığında public gerçek medya kabul edilir. Private adaylar, rejected kayıtlar ve branded fallback public gerçek medya olarak sayılmaz; fallback görüntü kullanılabilirliği korur ama schema/image-sitemap gerçek fotoğraf sinyali üretmez.
