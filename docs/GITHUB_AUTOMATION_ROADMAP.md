# GitHub Otomasyonu

Mevcut aşama: minimum yetkili CI, Dependabot (Composer, npm ve Actions), PR/issue şablonları ve kalite kontrolleri. Branch protection GitHub ayarından uygulanmalıdır: PR zorunluluğu, `CI / quality` zorunlu kontrolü, force-push engeli.

Staging/production deployment, Lighthouse ve Copilot otomasyonları sonraki fazlardadır.
