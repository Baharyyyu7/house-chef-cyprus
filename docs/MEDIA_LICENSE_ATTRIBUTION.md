# Media Licence and Attribution

Every approved public media record retains provider, source URL, licence, attribution and review timestamps. Pexels and Unsplash candidates retain creator metadata; Unsplash download tracking is performed only on final human selection. Missing licence or required attribution blocks `approved_real_media`.

AI output remains labelled as AI-generated and is not represented as a real photograph. Manual uploads require the copyright or contract record before final approval.
