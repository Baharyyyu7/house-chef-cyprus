## 2. AI Agent Sistemleri Nedir?

### 2.1 Tanım

AI agent sistemleri, belirtilen hedeflere ulaşmak için kendi kendini yöneten, planlayan ve çalışabilen yazılım agent'larıdır. Bu sistemler:

- **Kendini algılar** (self-aware): Durumu anlar ve değerlendirir
- **Planlar yapar** (planning): Adım adım yaklaşım oluşturur  
- **Çalışır** (execution): Kod yazar, komut çalıştırır, veri işler
- **Döngüye girer** (loop): Sürekli izler, analiz eder, iyileştirir

### 2.2 Bu Projekteki AI Agent Türleri

| Agent | Rol | Yetenek |
|-------|-----|---------|
| **SEO Audit Agent** | SEO analizi yapar | Teknik SEO, içerik kalitesi, schema analizi |
| **Autonomous Growth Engine** | Otonom büyüme motoru | Günlük 100/100/100 hedef (SEO, GEO, Backlink) |
| **Content Factory Agent** | İçerik üretir | Tarif ve blog oluşturma, zenginleştirme |
| **Backlink Agent** | Dış bağlantı analizi | Profil tarama, ulaşılabilirlik, outreach |
| **IndexNow Agent** | Arama motoru bildirimi | URL'leri Bing/Yandex'e anında iletir |
| **Auto-Fix Agent** | Otomatik düzeltme | Eksik metadata, kısa açıklamalar, eksik alt metinler |
| **Locale Growth Agent** | Dil bazlı büyüme | Her dil için durum analizi ve hazırlık |
| **Originality Scan Agent** | Tekrar içerik analizi | Benzersizlik kontrolü, duplicate content tespiti |
| **Internal Links Agent** | İç bağlantı analizi | Bağlantı önerileri, 404 tespiti |
| **Sitemap Agent** | Sitemap yönetimi | Dinamik sitemap oluşturma ve doğrulama |
