# RC1 yönetim regresyonu

Yönetim shell’i, içerik, medya, SEO, AI, veri kalitesi ve operasyon modülleri `access-admin` veya daha dar Gate’lerle korunur. Member, yönetim route’larında 403 alır. Yönetim ekranları boş/hata durumunda güvenli açıklama sunar ve ham payload, token veya stack trace göstermez.
