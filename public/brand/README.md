## Teknik not
SVG dosyaları, onaylı görselin görünümünü birebir korumak için yüksek çözünürlüklü şeffaf PNG verisini SVG kapsayıcı içinde taşır. Bu nedenle görsel olarak nettir ve Codex entegrasyonunda normal SVG asset gibi kullanılabilir; ancak gerçek path tabanlı vektör değildir.

Kompakt HCC markaları ana logodaki gerçek harf biçimlerinden türetilmiştir. Yayına alınmadan önce küçük ikonlarda okunabilirlik kontrolü yapılmalıdır.
